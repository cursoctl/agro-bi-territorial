# Catálogo inicial de KPIs

| KPI | Definição | Observação |
|---|---|---|
| Área plantada (ha) | Soma de área plantada dos registros filtrados | Evite duplicação se houver mais de um evento por plantio |
| Produção realizada (t) | Soma da produção de colheita | Unidade demonstrativa: toneladas |
| Produtividade (t/ha) | Produção / área colhida | Área colhida real é preferível a proxy |
| Custo total (R$) | Soma dos lançamentos de custo | Moeda fictícia em reais |
| Custo por hectare (R$/ha) | Custo / área plantada | Verificar escopo e período dos custos |
| Produção prevista (t) | Última previsão disponível por plantio | A view seleciona a previsão mais recente |
| Atingimento da previsão (%) | Produção realizada / prevista | Interpretar com cautela para safra ainda em andamento |
| Insumos aplicados | Quantidade por unidade cadastrada | Não somar unidades diferentes em um único KPI sem segmentar |
